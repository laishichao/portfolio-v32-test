V45 五项目高清版 · 分包下载说明

这是原先约285MB的完整网站，改为多个小 ZIP，内容没有减少。
1. 下载本系列全部编号 ZIP 文件。
2. 在电脑新建一个空文件夹（例如 V45_高清网站）。
3. 依次打开每个 ZIP，把 ZIP 内的文件与文件夹全部解压/复制到同一个 V45_高清网站文件夹。
4. Windows 询问是否合并同名文件夹时选“合并”。请不要把每个 ZIP 留在不同文件夹。
5. 最终保证 index.html、assets、projects 在同一根目录。双击 index.html 即可预览。
说明：这只是本地测试版，不要立即覆盖正式 GitHub 仓库。
