创作历程

从一件旧道具，走到一个完整故事

最初，我只是想制作一件带有时间痕迹的老化道具。选择示波器之后，我开始追问：它为什么会变旧、曾被谁使用、又被留在怎样的地方？这些问题逐渐把一件单独的道具，扩展成一间工作室、一个末日世界，以及一段关于出发与希望的故事。

01 / 起点

一台被时间留下的设备

我把它设定为一台曾被军方使用、后来因损坏而报废的设备。外壳上的腐蚀、报废标识与缺失零件记录着过去；末世物资匮乏，它又被幸存者重新找到并投入使用。

02 / 延展

为它寻找使用场景

我让它出现在一间废弃的地下室。这里被重新当作临时避难所，而这台残旧的示波器，则成为幸存者搜索同伴、接收外界信号的工具。

03 / 世界

让空间真正属于末日

我加入破旧座椅、锈蚀桌面、积灰管线与物资箱，建立避难所的生活痕迹；再以辐射灾难为背景，补充辐射检测仪、防毒面具，并在两侧墙面加入线索板与地图，让搜索行动留下记录。

04 / 希望

把路上看到的花带进结尾

一次徒步中偶然看到的花，让我想到希望不一定需要宏大的形式。它最终成为坐标尽头的发现，也给阴冷的画面留下温度。

作品从“如何做旧一台设备”，逐渐变成“它为什么被留下，又将人引向哪里”。

FILE 01 / OVERVIEW

一次来自废墟之外的信号

《末日示波器》是一组以废弃地下工作间为背景的环境叙事作品。幸存者通过一台旧式示波器接收到未知坐标，在地图上确认目标后携带装备离开，并最终在废墟中发现仍然生长的生命。

FILE 11—13 / DETAILS

设备细节与使用痕迹

高频接触区域以边缘抛光和油污为主，非操作区域保留积灰、掉漆与锈蚀。

资料整理 / 视觉方向

从资料中提取设计依据

我把收集到的资料分为设备结构、面板信息、空间氛围与旧化规律四组，用它们统一材质尺度和场景语言，而不是直接照搬某一张参考图。

参考资料来源：网页截图、Pinterest 与 Google 图片搜索，仅用于个人设计研究与视觉方向整理。

制作过程 / 材质、灯光与调色

让旧化服务于画面

制作重点放在材质再设计、场景整合、灯光推进与后期调色。每一步都围绕同一个目标：让设备既有可信的使用痕迹，也能成为故事的视觉中心。

步骤 01 / 材质再设计

面板材质逐层建立

以基础金属为起点，依次加入涂层剥落、锈蚀污迹与面板标识。旧化密度依据操作频率分配，而不是平均铺满整个表面。

步骤 02 / 灯光与后期调色

同一机位的画面递进

固定相机后，先用灰模验证空间关系，再逐步加入主光、设备功能光与体积氛围；最后在 AE 中统一冷暖关系、对比度与视觉焦点。
