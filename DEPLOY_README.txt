V31 Github Pages publish-ready package

1. Extract this archive. index.html must remain at repository root.
2. Create a new public repository, e.g. laishichao-portfolio.
3. Upload ALL unzipped files and folders to the root of the repository.
4. Settings > Pages > Build and deployment: Deploy from a branch, main, /(root).
5. Visit https://<your-github-username>.github.io/laishichao-portfolio/ after deployment.
